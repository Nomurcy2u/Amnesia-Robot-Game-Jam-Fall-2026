# Amnesia-Robot-Game-Jam-Fall-2026
A project for the GDAC Game Jam Fall 2026 which is based on the theme "unfamiliar" 
---
The project is an idea that you are a robot and you have lost your memories and functionalities. 
Waking up in this new world you rediscover your past through decryption puzzles and unlock new functionalities. 
How did you come to life? Where did you come from?
